Bu proje, Elasoft Bilişim şirketinde gerçekleştirdiğim staj sürecinde, YouTube üzerinde bulunan “Real Estate ASP.NET Core 8.0” eğitim serisinden faydalanılarak geliştirilmiş bir web uygulamasıdır.

Proje geliştirme sürecinde Visual Studio ortamında C# kullanılmış, veritabanı yönetimi için SQL Server tercih edilmiştir.

Uygulama, detaylı özelliklere sahip bir emlak sitesi niteliğinde olup, kullanıcıların ilanları görüntüleyebildiği, filtreleyebildiği ve sistem üzerinden çeşitli işlemler gerçekleştirebildiği bir yapı sunmaktadır.
